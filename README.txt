This ZIP archive is provided as a copy of all user data collected by the Scratch Foundation, including but not limited to metadata, user generated content in the form of comments, followers, following, and projects data.

In this file you should find a ZIP archive named 46009361_metadata.zip. If this account has projects, you will also find 46009361_projects.zip.
To open these files, either use your operating system's native handling of ZIP archives, or use the command line to open the files.

For example:
  unzip 46009361_metadata.zip
  unzip 46009361_projects.zip

The projects archive is a collection of SB3, SB2, and SB files. SB3 and SB2 files are ZIP archives and can be unarchived using the same ZIP program/method you used to open this file. SB files are Scratch 1 projects; the images and sounds are already inside the file. You can download the desktop version of Scratch and load these files individually into the editor/player to see each project in action. When an SB3 or SB2 file is unarchived, the images, sounds, and JSON file associated with the project will appear in the directory.

The metadata archive contains CSV files with information about followers, following, forum profile, forum posts, user profile, comments for profiles, studios, and projects, projects favorited, projects loved, studio memberships, user metadata, bans applied to this user, and IPs associated with this user.
